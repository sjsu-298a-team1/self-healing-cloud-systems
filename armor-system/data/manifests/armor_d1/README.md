# ARMOR D1 evidence manifests

Machine-readable evidence for Linear 298-43, generated by `armor-system/data/tools/`. Raw data is not stored here
(it lives in the Git-ignored `armor-system/data/raw/armor_zenodo_21744694/`).

| File | Produced by | Content |
|---|---|---|
| `provenance.json` | `fetch_d1.py` | Zenodo record, expected vs live metadata, excluded members |
| `checksums.json` | `fetch_d1.py` | Official md5, per-member CRC32/md5/sha256, bytes fetched vs not fetched, extraction record |
| `outer_archive_listing.csv` | `fetch_d1.py` | Every member of the official `ARMOR.zip` with size, CRC32 and whether it was fetched |
| `file_inventory.csv` | `inspect_d1.py` | The 9 extracted D1 files with size, format and sha256 |
| `channel_map.csv` | `inspect_d1.py` | 130 channel names with their modality |
| `label_mappings.json` | `inspect_d1.py` | Fine type to category, category names, node index |
| `class_distribution.csv` | `inspect_d1.py` | Per-class counts for all cases and ARMOR's 60/40 case split |
| `d1_inspection.json` | `inspect_d1.py` | Cases, features, scaling, split and leakage measurements |
| `d1_validation.json` | `validate_d1.py` | Hypothesis checks and the file re-hash result |

Human-readable summary: `armor-system/docs/d1_validation_report.md`.
